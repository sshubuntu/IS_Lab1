Объекты

Выберите раздел. Нажмите стрелку, чтобы развернуть все поля записи.
#{workspace.subcolumnCount(group)}

Для связанных полей выберите существующую запись. Создать её можно в соответствующем разделе меню.

Будет удалён объект #. Если на него ссылаются другие записи, выберите замену: все ссылки будут перенесены.
