Объекты

Выберите раздел. Нажмите заголовок колонки, чтобы отсортировать, и стрелку в строке, чтобы развернуть связанные объекты. Список сам обновляется, когда данные меняет другой пользователь.
Информация об объекте по ID

#{workspace.kind} ##{workspace.selectedId}
Фильтры
#{workspace.subcolumnCount(group)}

Для связанных полей выберите существующую запись. Создать её можно в соответствующем разделе меню.

Будет удалён объект #.

На объект ссылаются другие записи. Выберите замену — все ссылки перейдут на неё. Без замены вместе с объектом будет удалено записей: .
