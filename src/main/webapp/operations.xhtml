Специальные операции

Поиск по началу имени Возвращает работы, имя которых начинается с заданной подстроки. Понижение сложности Понижает сложность указанной работы на заданное число шагов. Программа дисциплины Привязывает десять самых сложных работ к указанной дисциплине. Удаление работ автора Удаляет все работы указанного автора. Удаление по минимальному баллу Удаляет одну работу с заданным минимальным баллом.
